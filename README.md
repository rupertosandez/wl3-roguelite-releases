# WL3 Roguelite beta builds

Beta builds of WL3 Roguelite, a mod that turns Wasteland 3 into a roguelite.

## Install

1. Download **WL3RogueliteTester.exe** from the [latest release](https://github.com/rupertosandez/wl3-roguelite-releases/releases/latest).
2. Close Wasteland 3 and run the app. Windows may warn about an unknown publisher: choose **More info**, then **Run anyway**.
3. Pick **Steam** or **Windows (Microsoft Store / Game Pass)**. The app finds the game folder; if it doesn't, use **Browse** and pick the folder that holds `WL3.exe`.
4. Press **Install**. Run the app again later and press **Update** when a new version is out.

**Uninstall** removes the mod and BepInEx and leaves the game's own files. Tick "Keep my settings and run history" to keep your progress for a later install.

In co-op, both players need the same version.
